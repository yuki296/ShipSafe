# ShipSafe v2.0 설계 초안 — 구현 대상 아님

## 목표와 모드

- Public Scan: v1의 DNS·CDN 네트워크 판별·공개 관측·HTTP 보안 설정 조회를 유지한다.
- Owner Scan: 소유권과 검사 권한을 확인한 대상만 허가된 범위 내에서 점검한다. Public 결과와 검증 수준을 별도로 표시한다.

## 아키텍처 후보

```text
React UI
  → Servlet API (모드·대상·권한·요청량 검증)
  → 제한된 작업 큐 (동시성·시간·출력 용량 한도)
  → 격리된 검사 워커 / PCAP 분석 워커
  → 결과 정규화 (관측 / 추론 / 검증된 사실)
  → React 결과 시각화
```

Tomcat은 Servlet 컨테이너로 사용한다. 검사 도구를 HTTP 요청 스레드에서 직접 실행하지 않는다. 초기에는 DB·로그인을 넣지 않고 만료되는 메모리 작업 ID로 결과를 조회하는 방안을 검토한다. 서버 재시작·다중 인스턴스에서 기록이 유실되는 한계를 명시한다. 민감한 진단 결과를 브라우저 이력에 자동 저장하는 정책은 별도로 결정한다.

## Owner Scan 진입 조건

1. DNS TXT 또는 HTTPS의 지정 경로에서 단기 난수 챌린지를 검증한다. 임의의 체크박스만으로 소유권을 인정하지 않는다.
2. 검증한 도메인·IP·포트·경로·검사 종류·유효기간을 서버가 서명한 단기 권한 토큰에 묶는다. 토큰은 로그에 남기지 않는다.
3. 도메인 제어만으로 공유 CDN IP 전체의 포트 스캔 권한을 인정하지 않는다. CDN 대상은 원본을 추적하지 않고 허용된 웹 경로 범위만 검토한다.
4. 유효 기간 내 DNS 변경·리다이렉트·최종 연결 IP를 매번 검증한다. DNS rebinding, IPv4/IPv6 사설·루프백·링크 로컬·예약·클라우드 메타데이터 주소, 내부망 경유를 차단한다.
5. 토큰/대상별 요청 한도·대기열 상한·동시 작업 한도·최대 실행시간·취소·보관기간·네트워크 출구 제한을 둔다. 쿠키 기반 세션을 쓰게 되면 CSRF 방어와 CORS 허용 출처를 설계한다.

## 단계별 후보

### 1. 서버 기반 Public Scan

기존 응답 모델을 재사용하고 CORS 의존성, 외부 API 제한, 캐시·타임아웃을 서버에서 관리한다. 백엔드를 붙여도 CDN을 원본으로 단정하지 않는다.

### 2. 제한된 Owner Scan

허가된 테스트 서버의 관리자 경로가 인증 없이 노출되는지 확인하되, 로그인 무차별 대입·자격증명 수집·권한 우회는 하지 않는다. HTTP 상태 코드만으로 접근 제어 취약점이 검증됐다고 판단하지 않는다.

OWASP ZAP은 먼저 수동 분석만 사용한다. 자동 스파이더·폼 제출·능동 스캔은 별도 허가·범위·제한이 필요하다. 능동 검사는 자체 테스트 환경에서만 허용하는 후속 단계로 분리한다. 프로세스 호출은 고정 실행파일·인수 목록을 사용하고 셸 문자열에 사용자 입력을 붙이지 않는다. 워커는 비특권·격리 환경에서 실행하고 파일/네트워크 권한을 제한한다.

### 3. 위험 시나리오 시각화

각 연결에 근거와 검증 수준을 붙인다. 예: ‘공개 포트 관측’ → ‘제품 버전 일치 시 잠재적 영향’은 추론으로 표시한다. 도구의 경고 자체를 실제 침해로 표시하지 않는다. 자체 환경의 재현 근거가 있을 때만 검증으로 분류한다.

### 4. 패킷 파일 분석

PCAP/PCAPNG 업로드를 먼저 검토한다. 파일 형식·확장자·용량·패킷 개수·압축/파싱 시간 한도, 안전한 임시 경로와 자동 삭제를 둔다. 패킷 내용에는 개인정보·인증정보가 있을 수 있으므로 기본 결과는 IP·포트·프로토콜·패킷 수·흐름 요약으로 제한한다. 텍스트·로그를 HTML로 실행하지 않는다.

실시간 수집은 별도 후속 기능이다. 본인이 관리하는 Linux 환경에서 명시적으로 선택한 인터페이스와 기간으로 제한한다. Tomcat에 root 권한을 부여하지 않는다.

## 착수 전에 확정할 사항

검사 허가의 증빙, ZAP 범위와 실행 환경, 큐/워커 격리 방식, 네트워크 차단 규칙, 보관/삭제 정책, 토큰 탈취 대책, 오류·취소 시 자원 정리 기준을 확정한다. 위 설계는 v1 완료를 위한 선행 조건이 아니다.
