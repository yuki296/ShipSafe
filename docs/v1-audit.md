## 결과 해석 계약

- `confirmed`: 공식 제공자 목록의 CIDR에 포함된 네트워크 IP. 그 도메인의 원본 IP라는 의미가 아니다.
- `unknown`: 현재 근거로 CDN 여부를 확정할 수 없음. CDN 아님을 뜻하지 않는다.
- `observed`: InternetDB 응답이 유효함. 실시간 포트 스캔 또는 공격 검증이 아니다.
- `no-data`: InternetDB HTTP 404. 보안 문제 없음이 아니다.
- `error`: HTTP·연결·시간 초과·응답 형식 오류. 빈 결과로 바꾸지 않는다.
- 데이터가 없는 이력의 포트/CVE 개수는 `null`(미확인)이다. 임의의 0건 결과를 만들지 않는다.
- Mozilla는 HTTP 설정 평가로만 표시한다. OSV는 패키지·버전과 일치한 권고이며 실제 악용 가능성 검증이 아니다.

## v1.0에서 하지 않는 일

IPv6, 모든 CDN 제공자 인식, 원본 IP 탐색/우회, 실시간 스캔, 로그인·DB·백엔드, ZAP 실행·패킷 수집은 구현하지 않는다. v2 설계는 별도 문서다.
